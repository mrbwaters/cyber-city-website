# Cyber City

Static site for [cybercitynovel.com](https://cybercitynovel.com), published with GitHub Pages from the `main` branch.

The site is intentionally buildless: edit the HTML, CSS, and JavaScript files directly. The `CNAME` file preserves the custom domain, and `.nojekyll` keeps GitHub Pages in static-file mode.

Chapters 1–13 are published as individual files under `chapters/`. Their text and public synopses are sourced from the private manuscript Google Doc; preserve the wording and inline emphasis when updating them.
